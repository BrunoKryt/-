советник

Внешний API

По умолчанию советник отвечает локально по каталогу. Можно указать POST-endpoint — тогда он сначала попробует нейросеть, а при ошибке вернётся к локальной базе.

Контракт API 
POST /advisor
{
  "message": "что посоветуешь на двоих?",
  "history": [{ "role": "user", "text": "..." }],
  "site": "indieforge"
}

Ответ:
{ "answer": "текст", "gameIds": ["it-takes-two"], "links": [] }

Подойдёт и OpenAI-совместимый ответ: choices[0].message.content.

осторожно

Опасная зона

Сброс каталога вернёт исходные 75 игр и удалит все правки, свои игры и скрытые карточки. Очистка обращений удалит всю переписку.

Исходный каталог и обращения хранятся в MariaDB. Правки, скрытые карточки и загруженные обложки — в этом браузере; для переноса используйте экспорт JSON.
